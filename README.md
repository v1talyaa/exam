# Економічна безпека Китаю — сайт для практичної частини іспиту

Автор: Віталій Боярчук  
Рік: 2026

## Структура
- `index.html` — сторінка автора.
- `china.html` — аналітична сторінка економічної безпеки Китаю.
- `css/style.css` — стилі.
- `js/data.js` — дані ключових індикаторів.
- `js/charts.js` — побудова графіків без зовнішніх бібліотек.
- `js/main.js` — меню та динамічні елементи.
- `assets/profile.png` — фото з резюме.

## Як опублікувати на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub, наприклад `china-economic-security`.
2. Завантажте в корінь репозиторію **весь вміст цього архіву**, зберігши папки `assets`, `css`, `js`.
3. Відкрийте `Settings` → `Pages`.
4. У `Build and deployment` оберіть `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`, натисніть `Save`.
6. Після публікації GitHub покаже адресу сайту. Головною сторінкою автоматично буде `index.html`.

## Перед здачею
Перевірте навігацію між `index.html` і `china.html`, відображення фото, графіків і таблиці на комп'ютері та смартфоні.
